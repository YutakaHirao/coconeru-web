6. CoconeRu 動画投稿ツールとTikTok連携

当社は、CoconeRu の情報発信のために、当社が運用する動画投稿ツール「CoconeRu」を通じて TikTok へ動画を投稿します。本ツールは TikTok Login Kit（OAuth 2.0）および TikTok Content Posting API を利用しており、利用者がTikTokの認可画面で明示的に許可した場合に限り、以下の権限を使用します。

user.info.basic
連携中のTikTokアカウントの表示名とプロフィール画像を画面に表示し、どのアカウントへ投稿するかを利用者が確認できるようにするために使用します。
video.publish
利用者が選択した動画を、利用者自身のTikTokプロフィールへ投稿するために使用します。
video.upload
動画を下書きとしてTikTokの受信箱へ送信し、TikTokアプリ上で編集してから公開できるようにするために使用します。

投稿は常に利用者の操作によって開始されます。CoconeRu が利用者に無断で投稿を行うことはありません。

利用者は、TikTokアプリの「設定とプライバシー → セキュリティとアクセス許可 → アプリの管理」から、いつでも CoconeRu の連携を解除できます。解除後、CoconeRu は当該アカウントに対する操作を行えません。

TikTok へ投稿するコンテンツについては、TikTokコミュニティガイドラインおよびTikTok利用規約を遵守します。

CoconeRu における個人情報および TikTok から取得した情報の取り扱いは、個人情報の取り扱いについてに定めるとおりです。
